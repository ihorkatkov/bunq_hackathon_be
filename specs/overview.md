# Bunq Investment Platform Overview

## Project Description
The Bunq Investment Coach is an AI-powered investment advisory platform designed for a 4-hour hackathon. It aims to demystify investment decisions for everyday banking customers by leveraging Bunq banking data to create personalized investment profiles and portfolio recommendations.

## Key Features
- Personalized investment profiles based on transaction history
- AI-powered portfolio recommendations based on risk tolerance
- Interactive chat interface for investment guidance
- Simple integration with Bunq API for transaction data

## Target Users
- Bunq banking customers
- Individuals new to investing
- Users seeking personalized investment guidance without high advisory fees

## Value Proposition
The Bunq Investment Coach bridges the gap between banking and investing by:
- Making investment accessible to everyone regardless of financial literacy
- Eliminating the complexity of investment decisions
- Providing personalized guidance based on actual spending behavior
- Offering a natural language interface that simplifies financial planning

## Project Scope
Given the 4-hour hackathon timeframe, the project focuses on:
- A minimal viable product with core functionality
- LLM-based analysis rather than custom ML models
- Basic but effective portfolio recommendations
- Simple user experience prioritizing clarity over complexity
